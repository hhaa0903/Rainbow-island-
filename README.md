# 彩虹冒險島 Rainbow Island

親子英語口說闖關遊戲（第一版原型）。玩家是兩姊妹 Chloe（8 歲）和 Joey（6 歲）：和島上的動物交朋友、幫忙處理生活小事，找回彩虹碎片。

## 怎麼開啟

不需要安裝或登入。直接用瀏覽器打開 `index.html`（`levels.js` 要放在同一個資料夾）。建議用平板或手機的 Chrome / Safari，橫向、直向都可以。

## 第一版內容

- 首頁選擇「Chloe 玩」「Joey 玩」「姊妹一起玩」。
- 小島地圖：五個地點。**迎賓碼頭**可完整遊玩；心情森林、家庭小屋、野餐商店、旅行車站是「下次冒險」故事預告，不能遊玩。
- 迎賓碼頭四組對話：認識朋友 → 今天的心情 → 準備飲料 → 道謝。
  - 單人：4 段；姊妹一起玩：前三組兩人輪流各一次，最後一起說 Thank you（共 7 段）。
- 每段：小兔子說話 → 孩子回應 → 視需要提示 → 家長按「繼續冒險」→ 場景回饋（徽章、心情貼紙、野餐籃、緞帶）→「下一段」。
- 結尾：彩虹恢復第一道顏色、船門打開、得到彩虹碎片；孩子選下次想去心情森林或家庭小屋；可再玩一次或換人玩。

## 操作說明

| 按鈕 | 用途 |
| --- | --- |
| 再聽一次 | 重播小兔子這一句 |
| 需要幫忙 | 顯示圖片提示和「英文小幫手」（更簡短的英文示範） |
| 中文小提示 | 家長打開才顯示中文意思與引導建議 |
| 參考回答 | 家長區內，預設收起；簡單版／進階版 |
| 慢一點／一般 | 英文語速 |
| 繼續冒險 | 家長確認後讓故事前進（不需要孩子說得「正確」） |
| 暫停 | 休息、從頭再玩，或結束冒險回地圖 |
| 喇叭 | 靜音（所有聲音） |

心情與飲料的圖片是理解提示，不是選擇題。孩子說了或指了哪一個，就點那張圖；沒點也可以直接繼續。

家長小叮嚀：先等約 5～10 秒，必要時用手勢，再提供提示；孩子願意嘗試就讓故事繼續。

## 功能限制與替代做法

- **英文語音**：使用瀏覽器內建語音合成（Web Speech API），聲音依裝置而不同。若裝置沒有語音或播放失敗，畫面會提示家長念出泡泡裡的英文句子，遊戲照常進行。
- **不會自動判斷孩子的回答**：是否前進一律由家長按「繼續冒險」。
- **麥克風「小耳朵」（選用，預設關閉）**：家長在家長面板勾選同意後才出現；按下時才請求麥克風權限，只聽一句就停止，聽到的字只顯示給家長參考，不評分、不判斷發音。瀏覽器內建辨識（如 Chrome）可能把聲音送到瀏覽器供應商的伺服器處理；本遊戲本身不錄音、不儲存、不上傳。不支援、拒絕權限或沒聽到時，直接按「繼續冒險」即可。
- **進度**：只存在瀏覽器本機（localStorage），記錄已探索地點、彩虹碎片、孩子下次想去的地點。無法儲存時（例如無痕模式）遊戲仍可玩，只是關掉後不會記得。完成地點代表「一起探索過」，不代表英文已熟練。

已測試：沒有可用語音、單人、姊妹輪流、換人玩、重玩、手機直向（無橫向捲動）。

## 新增每週關卡

關卡全部寫在 `levels.js`：

1. 找到地點（例如 `forest`），把 `status` 從 `"preview"` 改成 `"playable"`。
2. 照「迎賓碼頭」的格式補上 `host`、`intro`、`steps`、`ending`。
3. 每個 step 包含：角色台詞 `lines`、`helper` 小幫手、`zhTip` 中文提示、`answers` 參考回答、可選的 `cues` 圖片提示、`responses` 角色回應、`feedback` 場景回饋，以及姊妹輪流方式 `coop`（`each` / `alternate` / `together`）。

`index.html` 裡的 `FEEDBACK` 物件放場景動畫（`badgeName`、`badgeMood`、`basket`、`giftBadge`）；新場景如果需要新的動作，就在那裡加一個函式，並在資料裡引用它的名字。目前場景圖畫的是碼頭，其他地點要做成可玩時，還需要畫各自的場景。

建議每週：重複少量舊句型，加入少量新表達；3～5 組對話，約 5 分鐘，一次一題。
