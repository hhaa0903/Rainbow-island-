# 彩虹冒險島 Rainbow Island

親子英語口說闖關遊戲（第一版原型）。玩家是兩姊妹 Chloe（8 歲）和 Joey（6 歲）：和島上的動物交朋友、幫忙處理生活小事，找回彩虹碎片。

## 怎麼開啟

不需要安裝或登入。直接用瀏覽器打開 `index.html`（`levels.js` 要放在同一個資料夾）。建議用平板或手機的 Chrome / Safari，橫向、直向都可以。

## 第一版內容

- 首頁選擇「Chloe 玩」「Joey 玩」「姊妹一起玩」。
- 小島地圖：五個地點都可以完整遊玩。先玩**迎賓碼頭**，完成後心情森林、家庭小屋、野餐商店、旅行車站一起打開，順序隨孩子選。五塊碎片都找到時，彩虹全部恢復。
- 迎賓碼頭四組對話：認識朋友 → 今天的心情 → 準備飲料 → 道謝。
  - 單人：4 段；姊妹一起玩：前三組兩人輪流各一次，最後一起說 Thank you（共 7 段）。
- 每段：小兔子說話 → 孩子回應 → 視需要提示 → 家長按「繼續冒險」→ 場景回饋（徽章、心情貼紙、野餐籃、緞帶）→「下一段」。
- **簡單模式／挑戰模式**：開場卡片或家長面板切換。挑戰模式多 3 組對話：
  - 幾歲了：How old are you? → Eight.／I'm eight.（Joey：six）
  - 問小兔子心情：Your turn! Ask me. → How are you, Bunny?（由孩子主動發問，姊妹一起玩時兩人輪流擔任）
  - 揮手道別：Bye, Chloe! → Bye, Bunny!
  - 單人 7 段；姊妹一起玩 11 段，約 8 分鐘。
- 結尾：彩虹恢復第一道顏色、船門打開、得到彩虹碎片；孩子選下次想去心情森林或家庭小屋；可再玩一次或換人玩。

### 心情森林（第 2 週）

小熊 Bear 走得好累，樹上的小鳥 Bird 一個人有點難過。每段對話完成，森林就多開一朵花；結尾花全開、彩虹多一道顏色。

| 對話 | 角色說 | 孩子可以說 | 新／複習 |
| --- | --- | --- | --- |
| 認識小熊 | Hi! I'm Bear. | Hi!／Hi, Bear!／Hi! I'm Chloe. | 複習 |
| 小熊好累 | I'm tired. How are you? | Happy.／Sad.／Tired.（I'm …） | **新：I'm tired.** |
| 分享蘋果 | I like apples! | Me too!／No.（I like apples too!） | **新：Me too!** |
| 跟小鳥做朋友 | Bird is sad. Let's say hi! | Hi, Bird!（一起說） | 複習 |
| 挑戰：問小熊心情 | Your turn! Ask me. | How are you, Bear? | 複習 |
| 挑戰：關心小鳥 | （小鳥）I'm sad. | Are you okay?／Oh no! | **新：Are you okay?** |
| 挑戰：道別 | Bye, Chloe! | Bye, Bear! Bye, Bird! | 複習 |

### 家庭小屋（第 3 週）

小貓 Kitty 的帽子和球不見了。新句子：**Here it is!**、**Yes, please!**；挑戰：反過來問小老鼠 **What's your name?**、**Help, please!**、Bye, Kitty!

### 野餐商店（第 4 週）

松鼠幫大家裝野餐籃。新單字：**juice**、**banana**；複習 please / thank you；挑戰：**Excuse me!**、**How many?**（數蘋果）、Bye, Squirrel!

### 旅行車站（第 5 週）

小象站長 Ellie 和彩虹列車。新句子：**One ticket, please.**、**Let's go!**；複習名字、心情（表情會出現在火車窗戶）；挑戰：年紀、**Where to?**（海邊／山上／動物園）、Bye, Ellie!

完成任一關後，可以讓孩子選下次想去的地方；如果那裡已經打開，會出現「現在去…」按鈕。

### 多練口說

- **換你當角色**（開場卡片、家長面板或完成畫面的「換你當 ○○」）：孩子當小兔子、小熊、小貓、松鼠或站長，主動開口問問題或打招呼（What's your name? / How are you? / Water or milk? / Ticket? …），角色會回答，場景也會跟著變化。每關 4 組；姊妹一起玩時兩人都輪到，約 5 分鐘。較多提示時，會先播一次要說的句子讓孩子跟著說。
- **說長一點**：每一段在「英文小幫手」旁邊。孩子說了一個字（例如 Happy.）後按下，會播完整句（I'm happy.）讓孩子再跟著說一次。有圖片的題目，會播孩子選的那一句。

### 小遊戲廣場

首頁或地圖右上角的「小遊戲」。內容來自孩子去過的地點（單字約 20 個、句子約 17 句），沒有分數、倒數或紅叉；點錯時圖片會搖一搖、說出自己的名字，再試一次就好。姊妹一起玩時每一題輪流。

- **聽聽找找**：小兔子說一個單字，從三張圖片找出對的那張，再跟著說一次（6 題）。
- **翻翻卡**：4 組配對卡片，每翻一張都會念出英文，配對成功時大家一起說。
- **句子小火車**：聽一句話（I'm happy. / Juice, please. / Let's go to the zoo!…），找出對的圖片，火車就多一節車廂，再跟著說一次（5 句）。
- 「英文字」按鈕可以顯示或隱藏圖片下的英文字（Chloe 可以順便認字母）。

## 操作說明

| 按鈕 | 用途 |
| --- | --- |
| 再聽一次 | 重播小兔子這一句 |
| 需要幫忙 | 顯示圖片提示和「英文小幫手」（更簡短的英文示範） |
| 中文小提示 | 家長打開才顯示中文意思與引導建議 |
| 參考回答 | 家長區內，預設收起；簡單版／進階版 |
| 慢一點／一般 | 英文語速 |
| 繼續冒險 | 家長確認後讓故事前進（不需要孩子說得「正確」） |
| 暫停 | 休息、從頭再玩，或結束冒險回地圖 |
| 喇叭 | 靜音（所有聲音） |

心情與飲料的圖片是理解提示，不是選擇題。孩子說了或指了哪一個，就點那張圖；沒點也可以直接繼續。

家長小叮嚀：先等約 5～10 秒，必要時用手勢，再提供提示；孩子願意嘗試就讓故事繼續。

## 功能限制與替代做法

- **英文語音**：使用瀏覽器內建語音合成（Web Speech API），聲音依裝置而不同。若裝置沒有語音或播放失敗，畫面會提示家長念出泡泡裡的英文句子，遊戲照常進行。
- **不會自動判斷孩子的回答**：是否前進一律由家長按「繼續冒險」。
- **麥克風「小耳朵」（選用，預設關閉）**：家長在家長面板勾選同意後才出現；按下時才請求麥克風權限，只聽一句就停止，聽到的字只顯示給家長參考，不評分、不判斷發音。瀏覽器內建辨識（如 Chrome）可能把聲音送到瀏覽器供應商的伺服器處理；本遊戲本身不錄音、不儲存、不上傳。不支援、拒絕權限或沒聽到時，直接按「繼續冒險」即可。
- **進度**：只存在瀏覽器本機（localStorage），記錄已探索地點、彩虹碎片、孩子下次想去的地點。無法儲存時（例如無痕模式）遊戲仍可玩，只是關掉後不會記得。完成地點代表「一起探索過」，不代表英文已熟練。

已測試：沒有可用語音、單人、姊妹輪流、換人玩、重玩、手機直向（無橫向捲動）。

## 新增每週關卡

關卡全部寫在 `levels.js`：

1. 找到地點（例如 `forest`），把 `status` 從 `"preview"` 改成 `"playable"`。
2. 照「迎賓碼頭」的格式補上 `host`、`intro`、`steps`、`ending`。
3. 小遊戲的單字和句子寫在地點的 `practice`（`words`、`sentences`），圖示名稱要在 `ICONS` 裡有對應的圖。
3. 只在挑戰模式出現的對話，加上 `challengeOnly: true` 即可。
   「換你當角色」用的句子寫在 step 的 `roleplay`（孩子說 `say`、角色回答 `reply`）。
4. 每個 step 包含：角色台詞 `lines`、`helper` 小幫手、`zhTip` 中文提示、`answers` 參考回答、可選的 `cues` 圖片提示、`responses` 角色回應、`feedback` 場景回饋，以及姊妹輪流方式 `coop`（`each` / `alternate` / `together`）。

`index.html` 裡的 `FEEDBACK` 物件放場景動畫（例如 `badgeName`、`basket`、`bloom`、`shareApple`、`birdHappy`），`SCENES` 放各地點的場景圖（`dock`、`forest`、`house`、`shop`、`station`），`HOSTS` 放主角畫法（`bunny`、`bear`、`kitty`、`squirrel`、`elephant`）。資料裡也可以直接寫 `show:元素id`／`hide:元素id` 讓場景裡的東西出現或消失，`giveToken:圖示` 把小獎品放進孩子的收集欄。新地點要做成可玩時，需要在 `SCENES` 畫一張場景；動作和角色能沿用就沿用，在資料裡引用它們的名字即可。

建議每週：重複少量舊句型，加入少量新表達；3～5 組對話，約 5 分鐘，一次一題。
